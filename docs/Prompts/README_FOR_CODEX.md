# Codex Implementation Guide

## Mission
Build Human Civilization Atlas MVP using:
- Next.js 15
- TypeScript
- Tailwind CSS
- Prisma
- PostgreSQL (Supabase)

## Recommended Structure
src/
  app/
  components/
  lib/
  data/
  services/

## Build Order
1. Create project
2. Configure Prisma
3. Create database schema
4. Seed 10 civilizations
5. Build homepage
6. Build timeline page
7. Build civilization pages
8. Add search
9. Deploy to Vercel

## Definition of Done
- Deployment working
- Database connected
- Search working
- Timeline working
- 500 entities loaded
