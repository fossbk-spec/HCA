# HCA Product Requirements Document v1.0

## Product
Human Civilization Atlas (HCA)

## Goal
Xây dựng nền tảng tri thức về lịch sử, văn minh, nhân vật, ý tưởng và sách kinh điển.

## MVP Goals
- 500 knowledge objects
- Timeline Explorer
- Civilization Atlas
- Search
- Knowledge Graph Lite

## User Personas
- Student
- Teacher
- Researcher
- Lifelong Learner

## Core Features
1. Homepage
2. Timeline Explorer
3. Civilization Pages
4. People Pages
5. Book Pages
6. Idea Pages
7. Search
8. Related Knowledge Links

## Non Functional Requirements
- <2s page load
- Mobile responsive
- SEO friendly
- Accessible (WCAG inspired)

## Success Metrics
- 500 entities
- 100 DAU pilot
- 70% search success
